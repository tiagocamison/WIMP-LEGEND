# Historical poster pilot

`poster_workbench_pilot.ipynb` is a byte-for-byte copy of the preliminary notebook
from `f62e060ddedac75596a17e77af4053184dc07192`, before the configuration-driven
analysis replaced the active entry point. It is retained for historical reference,
not as a validated physical prediction.

Its original tables/configuration remain unchanged in
`../poster_workbench_assets/`. They do not feed the revised signal calculation.
If reproducing the original notebook, use `notebooks/` as its working directory
so its original relative asset paths resolve. Do not overwrite its asset files
with results from the new workbench.

Use `../poster_setup.ipynb` and `../poster_workbench.ipynb` for current work.
