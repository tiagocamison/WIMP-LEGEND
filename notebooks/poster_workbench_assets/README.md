# WIMP-LEGEND poster workbench assets

Preliminary pilot CSVs from 2026-10-26. These files are **not** certified LEGEND experimental projections.

- `pilot_component_rates.csv`: old/revised/alternative source-resolved backgrounds in events/(kg day keV observed).
- `pilot_sensitivity_results.csv`: pure-76Ge surrogate O1/O8/O11 median Poisson-CLs limits under specified assumptions.
- `pilot_config.json`: original benchmark assumptions, NOT measurement-calibrated.
- `pilot_manifest.json`: exact limitations/normalizations of the separate pilot analysis.

Replace with newly generated data on your branch when available, and never silently overwrite or relabel them.
